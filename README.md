# MUSE — Telegram business bot

Рабочий прототип системы записи для визажиста с тремя связанными интерфейсами:

- клиентский Telegram-бот;
- Telegram-админка по команде `/admin`;
- отдельная адаптивная веб-панель;
- общая база записей `data/bookings.json`.

Сторонние npm-пакеты не нужны: проект работает на Node.js 20+.

## Запуск веб-панели в демо-режиме

```powershell
$env:ADMIN_KEY="придумайте-ключ"
npm start
```

Откройте `http://localhost:3000`. Без `BOT_TOKEN` сервер запустит только веб-панель.

## Подключение Telegram

1. Создайте бота через `@BotFather` и получите токен.
2. Узнайте свой числовой Telegram ID.
3. Задайте переменные окружения:

```powershell
$env:BOT_TOKEN="токен BotFather"
$env:ADMIN_IDS="ваш Telegram ID"
$env:ADMIN_KEY="надёжный пароль веб-панели"
$env:PUBLIC_URL="https://адрес-панели.example"
npm start
```

Не добавляйте настоящий токен в Git и не записывайте его в `.env.example`.

## Сценарии

Клиент: `/start` → услуга → дата → свободное время → имя → телефон → заявка.

Администратор в Telegram: `/admin` → новые/все заявки → подтвердить или отменить. Клиент автоматически получает результат.

Веб-панель: вход по `ADMIN_KEY`, просмотр метрик и заявок, фильтрация, создание, подтверждение и отмена записи.

## Ограничения прототипа

- JSON-хранилище подходит для одного процесса и демонстрации; перед продакшеном заменить на PostgreSQL.
- Для production нужны HTTPS, reverse proxy, rate limiting, резервные копии и защищённая сессия вместо ключа в `sessionStorage`.
- Сейчас бот работает через long polling; при постоянном хостинге можно перейти на webhook.
